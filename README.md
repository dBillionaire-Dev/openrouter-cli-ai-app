# OpenRouter TypeScript CLI

A simple TypeScript CLI app that sends prompts to OpenRouter AI models.

## Setup

### Install dependencies

```bash
pnpm install
```

### Create a `.env` file

```env
OPENROUTER_API_KEY=your_api_key
MODEL_NAME=openai/gpt-4o-mini
```

## Run

```bash
pnpm dev "Explain TypeScript"
```
